# Yogesh & Karishma — Unique Wedding Invitation

A self-contained, mobile-first wedding invitation redesigned as a cinematic Indian wedding experience.

## Included
- Cinematic opening screen with Ganesha seal
- Traditional Indian couple artwork with varmala
- "Our Forever Starts Here" hero
- Wedding story and family blessing
- Live countdown to 07 December 2026, 7:30 PM IST
- Ceremony timeline
- Scratch-to-reveal शुभ विवाह surprise
- Both families' details
- Seven interactive vows
- December 2026 mini calendar
- Google Maps and Google Calendar actions
- Responsive/mobile-first layout
- Reduced-motion support
- No build step required

## Run
Open `index.html` directly in a modern browser, or serve the folder with any simple local HTTP server.

## Main editable data
`weddingDetails.js`
